# Students-System

This project implements a basic Student Management System using a list. Each student record contains an ID, age, and name, and is dynamically linked to the preceding and following students in the list. The system provides core functionalities to manage these records, allowing you to create new students, insert them at specific positions (first, last, or after a specific ID), update their details, search for individual profiles, and safely remove records from memory.

- How to use it:

```bash
gcc students_system.c -o ss
./ss
```
